# Layer 2: Main Skills (Kompositionen)

**Zweck:** Zusammengesetzte Skills, die Layer-0- und Layer-1-Primitives kombinieren. Nach Nutzungskontext gruppierbar.

**Abhängigkeiten:** Layer 0 (Core) und Layer 1 (Base).

**Verfügbare Skills:**

| Skill | Beschreibung | Dependencies |
|-------|-------------|-------------|
| `grill-with-docs` | Plan/Design-Review + ADR/Glossar-Erstellung in einer Session | `grilling`, `izg-domain-modeling` |

**Hinweis:** Skills hier sind keine Einzel-Primitives, sondern kombinieren mehrere Skills zu einem kohärenten Workflow.
